FALKORDB DATA SCHEMA

The graph is the investigation

RootCause follows recorded relationships in FalkorDB. The graph connects CI runs, failures, tests, functions, files, commits, incidents, and episodic agent memory.

(TestRun)-[:CONTAINS_FAILURE]→(Failure)-[:FAILED_TEST]→(Test) (Test)-[:EXERCISES]→(Function)-[:DEFINED_IN]→(File) (Commit)-[:CHANGED]→(Function) (Commit)-[:CHANGED_FILE]→(File) (Incident)-[:RESOLVED_BY]→(Commit) (Investigation)-[:RECORDED]→(AgentMemory) (Commit)-[:CHECKED_BY]→(Validation)

The agent chooses from fixed tools with authored Cypher queries. User text is never treated as Cypher.
